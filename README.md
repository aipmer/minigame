# 🎮 MiniGame — 现代 Web 3D 小游戏矩阵

轻量、纯粹、基于现代 Web 3D 技术与生成式 AI 资产的网页小游戏合集。

---

## 🕹️ 已收录游戏

### 1. 🐍 3D 贪吃蛇 (`games/snake3d/`)
- **引擎与图形**：Three.js r170+ (ACESFilmic 色调映射、深度太空雾、棋盘格反光地面、动态发光围栏)
- **3D 资产生成**：Tripo3D.ai 深度集成（包含 PBR 蛇头、蛇身节、红宝石食物、金色能量五角星、微光魔幻水晶簇障碍物，支持 Meshopt 工业级压缩解码）
- **玩法深度**：
  - 平滑插值网格移动与平滑转角 Slerp 追踪；
  - 动态 FOV（视场角随速度智能缩放）与相机跟随；
  - 5 秒连击 Combo 系统（高达 5 倍得分）；
  - 限时金色五角星道具（吃下后获得 5 秒无敌，可穿墙撞碎障碍物）；
  - 动态障碍物渐进升起；
- **纯代码音频**：Web Audio API 纯算法合成（吃食物上升清脆钟鸣、连击升调、关卡升级琶音、游戏结束低频下降音、无敌震音）；
- **全端操控**：支持桌面键盘（WASD / 方向键 / 空格）与移动端触屏滑动手势。

```
minigame/
├── index.html              # 游戏大厅导航聚合页

│       ├── css/style.css   # 游戏 UI 样式

└── vercel.json             # Vercel 静态托管配置
```

## 🚀 本地开发与预览

无需复杂的构建编译工具链，直接启动静态服务即可体验：

```bash
# 安装轻量本地静态服务依赖（如已全局安装可跳过）
npm install

# 启动本地服务
npm run dev
```

浏览器打开 `http://localhost:3000` 即可进入游戏大厅，点击游戏卡片即可直接畅玩！
